# DevOps Portfolio Lab [Junior set up]
A hands-on DevOps project covering Linux, Docker, Kubernetes, 
Ansible, and cloud-native practices, built entirely on a single Ubuntu LTS
Server v24.04 VM.

## Why this project exists
I built this portfolio to develop and demonstrate the practical 
skills needed for a Cloud Engineer role in companies that focuses on 
data sovereingty and deploy its infrastructure using open source 
tools like Open Stack. 
It focuses on real-world practices like automation, containerisation, 
infrastructure as code, and monitoring, with an emphasis on 
understanding data sovereignty and cloud-native systems.

## Project Phases
- **Phase 1 – Linux Fundamentals** → [View scripts](./phase1)
- **Phase 2 – Docker & Observability** → [View projects](./phase2/docker)
- **Phase 3 – Kubernetes** (in progress)
- **Phase 4 – Kubernetes Security**
- **Phase 5 – Ansible & GitLab CI/CD**
- **Phase 6 – Integrated Project**

Key highlights
- Prometheus and Grafana for system monitoring
- Multi-service appliction (Flask, MySQL, Redis) behind an Nginx reverse proxy
- Infrastructure as Code using Ansible playbooks (work in progress)
- GitLab CI/CD pipeline set up (in progress)
- Exploration of OpenStack concepts for data sovereingty in cloud environments
